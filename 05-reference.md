## Справочная информация

Здесь собраны технические параметры, команды для диагностики и тексты сообщений, которые могут пригодиться при работе с приложением.

### Параметры настройки приложения

Эти параметры задаются в файле `build.gradle` при сборке приложения.

| Параметр | Назначение | Пример значения |
| :--- | :--- | :--- |
| `DATABASE_NAME` | Имя файла базы данных SQLite | `kirill_notes.db` |
| `DATABASE_VERSION` | Версия схемы базы данных | `1` |
| `LOG_LEVEL` | Уровень логирования | `DEBUG` / `INFO` / `ERROR` |
| `MAX_NOTEBOOKS` | Максимальное количество записных книжек | `100` |
| `MAX_NOTES_PER_NOTEBOOK` | Максимальное количество заметок в одной книжке | `1000` |

### Команды ADB для диагностики

Эти команды выполняются на компьютере при подключённом по USB мобильном устройстве.

| Команда | Назначение |
| :--- | :--- |
| `adb shell pm list packages \| grep kirill` | Проверка установки приложения |
| `adb shell "run-as com.example.kirill ls /data/data/com.example.kirill/databases/"` | Проверка наличия базы данных |
| `adb shell "run-as com.example.kirill sqlite3 /data/data/com.example.kirill/databases/kirill_notes.db 'SELECT * FROM notes;'"` | Просмотр списка заметок в БД |
| `adb shell dumpsys meminfo com.example.kirill` | Проверка использования памяти |
| `adb logcat -d \| grep -i "Kirill"` | Просмотр логов приложения |

### Сообщения оператору (пользователю)

| Текст сообщения | Содержание | Действия оператора |
| :--- | :--- | :--- |
| «Введите название записной книжки» | Поле названия оставлено пустым | Заполнить поле и повторить сохранение |
| «Записная книжка с таким именем уже существует» | Попытка создать дубликат | Ввести другое название |
| «Удалить заметку?» | Запрос подтверждения | Нажать «Да» или «Отмена» |
| «Удалить записную книжку и все заметки внутри неё?» | Запрос подтверждения | Нажать «Да» или «Отмена» |
| «Недостаточно места на устройстве» | Свободно менее 10 МБ | Освободить место на устройстве |

## Устранение неисправностей (FAQ)

### Приложение не запускается. Что делать?

1. Перезагрузите устройство.
2. Убедитесь, что версия Android соответствует требованиям (Android 12+).
3. Попробуйте переустановить APK-файл.
4. Если проблема сохраняется — проверьте логи через ADB (см. команды выше).

### Заметки не сохраняются или приложение «вылетает»

1. Проверьте свободное место на устройстве (должно быть не менее 100 МБ).
2. Закройте приложение полностью (через меню запущенных приложений) и откройте заново.
3. Если ошибка повторяется — проверьте логи `adb logcat`. Возможно, повреждена база данных.

### Как восстановить данные из резервной копии?

Если вы заранее создали резервную копию (файл `kirill_notes_backup.db`):

1. Удалите приложение с устройства (это удалит и повреждённую базу данных).
2. Установите приложение заново.
3. Запустите его один раз, чтобы создалась новая пустая база.
4. Скопируйте ваш файл `kirill_notes_backup.db` в папку приложения на устройстве, заменив текущий файл базы данных (требуются права root или ADB).
5. Запустите приложение — данные должны восстановиться.

> **Важно:** без резервной копии восстановить удалённые заметки невозможно. Приложение не хранит данные на сервере.

### Почему приложение не работает без интернета?

Это нормально. Приложение «Kirill» является полностью автономным. Все данные хранятся локально на устройстве, и подключение к сети не требуется.

### Как обновить приложение?

1. Если приложение установлено из Google Play — обновление произойдёт автоматически.
2. Если установлено вручную (APK) — скачайте новую версию с внутреннего портала или из доверенного источника и установите поверх старой. База данных сохранится.
