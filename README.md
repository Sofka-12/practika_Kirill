# practika_Kirill

Документация к мобильному приложению **Kirill** — приложению для ведения заметок с организацией по записным книжкам.

## О проекте

Этот репозиторий содержит полный комплект технической документации для приложения Kirill, оформленной в формате Markdown. Документация структурирована по ролям пользователей и объединяет материалы всех этапов разработки: от внедрения до сопровождения и выпуска обновлений.

## Как просматривать документацию

### Вариант 1. На GitHub/GitLab

1. Откройте файл [index.md](index.md) — это главная страница документации.
2. Переходите по ссылкам между разделами.
3. Все изображения находятся в папке `images/`.

### Вариант 2. Локально в Visual Studio Code

1. Откройте папку проекта в VS Code.
2. Установите расширение **Markdown Preview Enhanced** (или используйте встроенный просмотр).
3. Откройте `index.md` и нажмите `Ctrl+Shift+V` для предпросмотра.

## Технические характеристики приложения

- **Тип:** мобильное приложение для Android
- **Версия:** 1.0.0
- **Язык:** Kotlin (Jetpack Compose)
- **База данных:** SQLite через Room
- **Режим работы:** автономный (без сервера)
