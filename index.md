## О приложении

**Kirill** — это мобильное приложение для ведения личных заметок на платформе Android. Приложение позволяет создавать, редактировать, удалять и организовывать текстовые заметки по **записным книжкам**, что обеспечивает удобную структуризацию личной информации.

Приложение работает **полностью автономно**: не требует подключения к интернету, не использует внешние серверы и хранит все данные локально на устройстве пользователя в базе данных SQLite.

## Назначение

Приложение предназначено для:

- создания и хранения текстовых заметок;
- организации заметок по записным книжкам;
- быстрого поиска нужной информации;
- работы без подключения к сети.

Приложение будет полезно студентам, специалистам и всем, кто ведёт личные или рабочие записи на смартфоне.

---

## Основные возможности

- **Создание записных книжек** — для группировки заметок по темам.
- **Создание заметок** — с заголовком и текстом.
- **Редактирование заметок** — изменение заголовка и содержимого.
- **Перемещение заметок** — между записными книжками.
- **Удаление заметок и записных книжек** — с подтверждением.
- **Выбор цвета обложки** — для визуального различения записных книжек.
- **Резервное копирование** — создание копии базы данных.
- **Экспорт данных** — выгрузка заметок в формате JSON.
